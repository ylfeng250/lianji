# 练迹 · 交互设计说明

这份文档记录「练迹」1.1 交互升级的产品决策。目标是让一个人在健身房里单手、出汗、赶时间的状态下，
用最少的点击完成记录；同时让删除这类危险操作永远可以撤回。

参考了 GymMane（离线训练记录、把肌肉/组/休息做成一条动线）和 LibreFit（Compose + Room、动作筛选、
Material 3）的公开产品截图与说明，只借鉴交互思路，不复制它们的 GPL 代码。动作图继续来自
workout-guide（CC BY-SA 4.0）。

## 一条手势语言

| 手势 | 含义 | 用在哪里 |
|---|---|---|
| 轻点 | 打开 / 选中 | 所有列表 |
| 长按 | 进入多选，再点切换 | 动作库、历史、计划里的动作 |
| 右滑 | 正向动作：收藏、开始 | 动作库 |
| 左滑 | 快速动作：加入训练 | 动作库 |
| 左滑（危险） | 删除，必带「撤销」 | 训练中的组、计划动作、历史记录 |
| 左右翻页 | 上一个 / 下一个动作 | 动作详情 |

规则：

1. **危险操作只走一条路**：删除一律左滑或菜单，执行后底部出现「撤销」，超过一次误触成本。
2. **删除不弹确认框，但永远可撤销**：确认框会打断节奏；撤销条更快。整场训练、计划这类大对象才用确认框。
3. **多选不改变布局**：长按进入，顶部栏换成「已选 N 项」，底部出现批量操作条，退出即恢复。
4. **每一步都有反馈**：滑动到阈值有触感，收藏/加入/删除都有轻提示。
5. **数字用步进器，精确输入才弹键盘**：健身房单手点 ± 比调键盘快；点数值再弹输入框。

## 各页面

### 今日

- 顶部问候 + 本周三块数据（次数、容量、连续天）。
- 正在进行的训练置顶，显示已练时长，一键继续。
- 计划卡片右侧直接「开始」，不用先进计划再点开始。
- 近期个人纪录保留为轻量列表。

### 动作库

- 搜索 + 肌群快筛；「筛选」底部面板收器械、训练类型、只看收藏、只看有步骤。
- 排序：名称（按拼音）、肌群、器械、收藏优先；肌群和器械按训练时常见的顺序排。
- 长按多选：批量收藏/取消收藏、加入计划、加入训练；从计划/训练里进来时变成批量添加。
- 右滑收藏，左滑直接加入当前训练（没有进行中的训练就从自由训练开始）。
- 空结果、无收藏、无步骤都有明确文案。

### 动作详情

- 横向翻页在动作之间切换，标题随页面更新，回到列表不增加返回层级。
- 动作图可播放/暂停，点下方圆点切帧；三帧循环，默认自动播放。
- 显示「上次训练」：最近三次的重量 × 次数，方便决定今天加不加重量。
- 底部固定「开始训练」「加入计划」两个动作。

### 训练中

- 休息计时固定在顶部，不随列表滚走；显示进度条和「下一个」动作。
- 每组一行：组类型、重量步进器、次数步进器、完成圆钮。点数值可精确输入，RPE 和备注收进编辑面板。
- 左滑删组，可撤销；「加一组」自动沿用上一组的重量和次数。
- 每个动作卡片右上角菜单：上移、下移、替换、全部完成、删除（撤销）。
- 动作标题下显示「上次 60 公斤 × 8」，避免凭记忆加重。
- 底部固定「添加动作」「完成训练」。

### 训练计划

- 列表可新建、套用推/拉/腿模板；左滑删除计划（撤销），长按批量删除。
- 编辑页：动作卡片显示组数、次数、休息摘要；左滑移除动作（撤销），长按多选批量移除。
- 「编辑目标」面板改每组次数/重量、增删组；休息时间用 ±15 秒步进。

### 数据与历史

- 「概览 / 历史」分段切换，概览保留周次数、周容量、肌群组数、日历和当日训练。
- 历史按月份分组，点击进训练详情；左滑删除（撤销），长按批量删除。
- 训练详情只读展示每个动作的每组数据，提供「再来一次」和删除。

### 我的

- 设置项改成行式布局：单位、主题用分段选择，休息时间用步进，其余用开关。
- 导入导出仍然走系统文件选择器，导入前有一次确认。

## 工程上踩过的坑

- 动作图靠运行时名字查找，发布包必须用 `res/raw/keep.xml` 保留，否则资源压缩会把 906 张图全部删掉。`assembleRelease` 结束时会核对。
- Room 的 `@Insert(onConflict = REPLACE)` 会先删父行再插入。计划、动作、组是父子表并且开了 `ON DELETE CASCADE`，所以更新计划必须用 `@Update`，否则改一次目标就会把动作和组级联删掉。`RoutineRepositoryTest` 是这条的回归测试。
- 底部面板内容要用 `verticalScroll` + `heightIn` 并默认完全展开，否则在小屏上「完成」按钮会滑不到。

## 不做的事

- 不引入账号、云同步和网络权限。
- 不做需要联网的动作视频/GIF。
- 不复制 GymMane / LibreFit 的源码；只在「关于」里注明交互参考来源。
- 不删除 free-exercise-db 的文字步骤，但也不使用它的图片。
